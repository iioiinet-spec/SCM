  • 형식을 고정한다 — "HTML 파일 하나"로 저장과 실행이 간단해집니다.

[동작]
- 마우스를 카드 위에서 움직이면 그 방향으로 최대 12도까지 기울어지게
- 아바타와 이름은 카드보다 조금 더 앞으로 떠 보이게

HTML 파일 하나로, 색과 각도는 맨 위에서 쉽게 바꿀 수 있게 정리해줘.
  • 대괄호로 묶는다 — [모양]과 [동작]을 나누면 AI가 빠뜨리지 않습니다.
  • 한계값을 정한다 — "최대 12도"가 없으면 카드가 과하게 꺾입니다.
  • 수정 지점을 요청한다 — "맨 위에서 바꿀 수 있게"가 다음 단계 실습을 쉽게 만듭니다.

✓ 앞 카드에 이어서 넣는 프롬프트
방금 만든 카드에 이어서 두 가지만 추가해줘.

1) 카드 아래쪽에 테두리만 있는 분홍색 둥근 버튼 "비밀 열기"를 넣어줘.

알고 가기 — 게임은 1초에 60번 도는 4단계

① 입력 → ② 이동

지금 눌린 키를 확인하고, 캐릭터와 장애물의 위치를 조금씩 바꿉니다.

③ 충돌 검사

두 사각형이 겹쳤는지 확인합니다. 겹치면 게임 종료, 아니면 점수 +1.

④ 다시 그리기

화면을 지우고 새 위치에 전부 다시 그립니다. 이 네 단계의 반복이 게임입니다.

규칙을 먼저 문장으로 — "무엇을 조작하고 / 무엇을 피하고 / 언제 점수가 오르고 / 언제 끝나는가". 이 네 문장이 없으면 프롬프트를 쓸 수 없습니다.

실습 프롬프트 3종

3-1무대와 조작 — 방향키로 움직이는 플레이어
✓ 실습 프롬프트
캔버스로 만드는 "별 피하기" 게임의 1단계를 만들어줘.
지금은 플레이어 이동까지만, 장애물은 아직 넣지 마.

[무대]
- 가로 480px, 세로 560px 캔버스, 배경은 아주 어두운 남색
- 화면 가운데 정렬, 캔버스 모서리는 14px 둥글게

[플레이어]
- 바닥에서 40px 위에 있는 가로 44px, 세로 44px 노란 사각형
- 왼쪽·오른쪽 방향키를 누르고 있는 동안 1초에 320px 속도로 이동
- 벽 밖으로는 나가지 못하게

[중요]
- 키를 누르는 순간에만 한 칸 움직이지 말고,
  누르고 있는 동안 계속 부드럽게 움직이게 해줘
- 화면 갱신은 requestAnimationFrame으로 하고,
  기기가 달라도 속도가 같도록 시간 간격을 반영해줘

HTML 파일 하나로 만들어줘.
  • 단계를 자른다 — "장애물은 아직"이 한 번에 확인 가능한 크기를 만듭니다.
  • 속도를 초 단위로 — "1초에 320px"은 프레임 수와 무관한 정확한 표현입니다.
  • 흔한 실수를 미리 막는다 — 눌린 상태 유지 이동을 콕 집어 요구합니다.
3-2장애물 · 충돌 · 점수 — 게임이 되는 순간
✓ 실습 프롬프트
이어서 2단계로 장애물과 점수를 넣어줘.

[장애물]
- 0.7초마다 화면 맨 위 임의의 x 위치에서 별 하나가 생김
- 지름 26px 정도, 아래로 1초에 220px 속도로 떨어짐
- 화면 아래로 완전히 나가면 목록에서 지워서 쌓이지 않게

[점수]
- 별이 플레이어에 닿지 않고 바닥을 지나가면 1점
- 점수는 캔버스 왼쪽 위에 20px 글씨로 표시

[충돌]
- 별과 플레이어의 사각형이 겹치면 즉시 게임 오버
- 게임 오버 화면에 최종 점수와 "다시 하기" 안내를 띄우고
  스페이스바를 누르면 처음부터 다시 시작

한 번에 화면에 있는 별이 30개를 넘지 않게 제한해줘.
  • 생성·소멸을 같이 적는다 — 지우는 규칙이 없으면 게임이 점점 느려집니다.
  • 점수 조건을 정확히 — "닿지 않고 지나가면"이 판정 시점을 정합니다.
  • 상한을 둔다 — 최대 개수 제한은 성능 사고를 막는 안전장치입니다.
3-3난이도 곡선 · 최고 점수 · 모바일 조작
✓ 실습 프롬프트
마지막 3단계로 게임을 완성해줘.

[난이도]
- 10초마다 별의 낙하 속도가 12% 빨라지게
- 생성 간격도 10초마다 0.05초씩 짧아지되, 0.25초보다는 짧아지지 않게
- 현재 단계를 "LV.3"처럼 오른쪽 위에 표시

[기록]
- 최고 점수를 화면에 같이 표시하고, 새 기록이면
  게임 오버 화면에 "신기록!"을 노란색으로 띄워줘

[모바일]
- 화면 폭이 좁으면 캔버스 아래에 왼쪽·오른쪽 버튼을 보여주고
  누르고 있는 동안 이동하게
- 캔버스를 터치해도 화면이 스크롤되지 않게

[마무리]
- 게임 시작 전 "방향키로 이동, 별을 피하세요" 안내 화면 넣기
- 코드 맨 위에 속도·간격 같은 숫자를 한곳에 모아 주석과 함께 정리
  • 상승과 하한을 함께 — 하한이 없으면 몇 분 뒤 게임이 불가능해집니다.
  • 기록은 동기를 만든다 — 발표 시간에 친구들끼리 기록 경쟁이 붙습니다.
  • 설정값을 모은다 — 발표 직전 난이도 조정을 프롬프트 없이 직접 할 수 있습니다.

내 링크 만들기 — GitHub Pages 5단계

1

파일 이름을 index.html로 바꾸기

이름이 index.html이어야 주소만 입력해도 바로 열립니다. 파일은 폴더 맨 바깥에 둡니다.

2

GitHub에서 새 저장소 만들기

이름은 영문 소문자와 하이픈으로 (예: star-dodge). 공개 범위는 Public으로 두어야 친구가 접속할 수 있습니다.

3

파일 올리기

저장소 화면에서 Add file → Upload files를 누르고 index.html을 끌어다 놓은 뒤 Commit changes를 누릅니다.

4

Pages 켜기

Settings → 왼쪽 메뉴 Pages → Branch를 main / /(root)로 지정하고 저장합니다.

5

1~2분 뒤 주소 확인

같은 화면 위쪽에 https://아이디.github.io/저장소이름/ 주소가 나타납니다. 휴대폰으로도 열어보세요.

더 빠른 방법 — 계정 만들기가 부담되면 Netlify Drop에 폴더를 끌어다 놓기만 해도 즉시 링크가 생깁니다. 다만 주소가 무작위이고 관리가 어려우니, 오래 남길 작품은 GitHub Pages를 권합니다.
