01 — Design Principles

설계 원칙

중등부 1차 대비는 C11로 통일합니다. STL이 없는 환경을 제약이 아니라 자료구조를 직접 만들어 보는 기회로 삼아, 라이브러리 사용법이 아니라 내부 동작을 아는 학생을 기릅니다.

문법은 알고리즘의 도구로 가르친다

PART 1의 모든 문법 항목은 뒤에서 쓰일 자리를 미리 지정합니다. 포인터는 스택·연결 리스트를 위해, 구조체는 간선 목록과 qsort 비교 함수를 위해, 2차원 배열은 격자 BFS를 위해 배웁니다.

STL 없이 직접 구현한다

정렬은 qsort와 직접 구현을 함께, 스택·큐·덱은 배열로, 우선순위 큐는 이진 힙으로, 집합은 비트마스크와 유니온 파인드로 만듭니다. 2차 진출 이후 C++20을 별도 보충 과정으로 둡니다.

난도는 티어 라벨로 관리한다

브론즈·실버·골드는 문제 출처가 아니라 난도 기준으로 씁니다. 각 파트의 문제는 자체 제작을 원칙으로 하고, 티어는 요구 알고리즘·제약 조건·구현량으로 정의한 내부 기준표를 따릅니다.

모든 코드는 기준 정답으로 검증한다

예제·연습·평가의 모든 코드는 gcc로 컴파일해 실행 결과를 확보하고, 파이썬 독립 구현과 대조해 기준 정답을 확정합니다. 검증되지 않은 코드는 교재에 싣지 않습니다.

시간복잡도를 1장부터 말한다

PART 2 초반에 "1초 ≈ 1억 연산"을 도입하고, 이후 모든 장에서 제약 조건(N의 범위)을 먼저 읽고 알고리즘을 고르는 절차를 반복 훈련합니다. 티어가 오를수록 이 판단이 정답률을 가릅니다.

오답은 유형으로 분류해 되돌린다

각 파트 마지막 장은 실전 모의와 오답 유형 정리입니다. 틀린 이유를 개념 미흡·구현 실수·시간 초과·경계 처리 네 범주로 나누고, 범주별로 돌아갈 장을 지정해 둡니다.

03 — Chapter Format

교재 구성 표준

모든 장은 아래 7개 블록을 같은 순서로 갖습니다. 분량은 장당 본문 12~16쪽, 문제 20문항을 기준으로 합니다.

  1. 도입 문제— 이 장의 도구가 없으면 풀기 번거로운 작은 문제를 먼저 던져 필요를 만든다
  2. 개념 정리— 정의, 동작 원리, 그림 또는 표로 표현한 내부 상태 변화
  3. 표준 코드— 그대로 외워 쓸 수 있는 기준 구현 1개. gcc 검증 완료본만 수록
  4. 단계 예제— 표준 코드를 조금씩 변형하는 예제 4~5개, 각 예제마다 실행 결과 명시
  5. 흔한 오류— 이 장에서 학생이 실제로 내는 실수 3~4가지와 증상·원인·수정
  6. 연습 문제— 20문항(기본 8 · 응용 8 · 심화 4). 문제 본문을 교재에 전문 수록
  7. 확인 평가와 해설— 별책 해설지에 기준 정답 코드, 복잡도 분석, 대안 풀이 수록

두 가지 판본으로 분리

교사용 통합본은 정답 코드·해설·채점 기준·수업 진행 노트를 포함하고, 학생 배부용은 문제와 개념만 싣습니다. 본문은 같은 원고에서 생성해 두 판본이 어긋나지 않게 합니다.

판정 사이트에 의존하지 않는다

연습 문제는 본문에 전문 수록하고, 기준 정답 코드와 자체 채점 스크립트를 부록으로 제공합니다. 외부 사이트가 바뀌어도 교재만으로 학습과 채점이 끝납니다.
