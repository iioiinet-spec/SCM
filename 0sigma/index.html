1-1시그마 기호 해부하기

시그마(Σ)는 그리스 문자로, "규칙에 따라 여러 개의 수를 전부 더하라"는 뜻입니다. 1 + 2 + 3 + ... + 100 처럼 길게 쓰는 대신 기호 하나로 압축합니다.

아래끝(시작) i=1,  위끝(끝) n,  일반항(더할 식) ai  →  Σi=1n ai = a1 + a2 + ... + an

읽는 법: "i가 1부터 n까지 변할 때, ai를 모두 더한 값". 변수 i를 인덱스(첨자)라고 부르며, 코딩의 for문 반복 변수와 정확히 같은 역할을 합니다.

핵심 직관 — 시그마 기호를 보면 무조건 이렇게 번역하세요: 아래끝 = 반복 시작값, 위끝 = 반복 끝값, 일반항 = 누적할 식

2-1반드시 외워야 할 3대 합 공식

① Σi=1n i = n(n+1)/2   // 1+2+...+n
② Σi=1n i² = n(n+1)(2n+1)/6
③ Σi=1n i³ = { n(n+1)/2 }²   // ①의 제곱!

그리고 상수의 합: Σ c = c × n (c를 n번 더하는 것).

검산 습관 — n=3을 대입해 보세요. ① 3·4/2=6=1+2+3 ✓  ② 3·4·7/6=14=1+4+9 ✓  ③ 6²=36=1+8+27 ✓. 공식이 헷갈리면 항상 작은 수로 검산!

2-2가우스의 짝짓기 — 공식 ①이 성립하는 이유

1부터 n까지의 합을 앞뒤로 짝지으면 모든 쌍의 합이 (n+1)로 같아집니다. 쌍이 n/2개이므로 합은 n(n+1)/2. 아래에서 n을 바꿔가며 직접 확인해 보세요.

n = 10 → 쌍의 합 11이 5쌍 → 합계 55

2-3시그마의 성질 (선형성) — 식을 쪼개는 기술

복잡한 시그마는 쪼개고, 상수를 밖으로 빼서 3대 공식으로 환원합니다.

Σ(ai + bi) = Σai + Σbi     Σ(c·ai) = c·Σai

예제: Σ(3k+2), k=1..50 을 암산 수준으로

Σ(3k+2) = 3·Σk + Σ2 = 3·(50·51/2) + 2·50 = 3·1275 + 100 = 3925
주의! Σ(ai·bi) ≠ (Σai)·(Σbi) — 곱은 쪼개지지 않습니다. 예: Σi² (=385, n=10) 과 (Σi)² (=55²=3025) 는 완전히 다른 값!

3-2단계 1 — 단일 시그마

난이도 ★☆☆

Σi=110 i 를 코드로 옮기면? (정답: 55)

Csum1.c
// 1부터 10까지의 합
#include <stdio.h>
int main(void) {
    int s = 0;
    for (int i = 1; i <= 10; i++)
        s += i;             // 일반항
    printf("%d\n", s);  // 55
}
Pythonsum1.py
# 1부터 10까지의 합
s = 0
for i in range(1, 11):  # 10+1 !
    s += i
print(s)   # 55

# 한 줄 버전 (시그마 그 자체)
print(sum(i for i in range(1, 11)))

3-3단계 2 — 조건이 붙은 시그마

난이도 ★★☆

"1~100 중 3의 배수만 더하라" = Σi=1..100, 3|i i. 조건은 if문으로 번역됩니다.

Ccond.c
int s = 0;
for (int i = 1; i <= 100; i++)
    if (i % 3 == 0)   // 조건 = if
        s += i;
// s = 3+6+...+99 = 1683
Pythoncond.py
s = sum(i for i in range(1, 101) if i % 3 == 0)
print(s)  # 1683

# 공식 풀이: 3(1+2+...+33) = 3·33·34/2 = 1683

3-4단계 3 — 이중 시그마 = 이중 for문

난이도 ★★★

시그마가 두 개 겹치면 for문도 두 개 겹칩니다. 바깥 시그마 = 바깥 루프, 안쪽 시그마 = 안쪽 루프.

Σi=110 Σj=110 (i+j) = 1100
Cdouble.c
long long s = 0;
for (int i = 1; i <= 10; i++)      // 바깥 Σ
    for (int j = 1; j <= 10; j++)  // 안쪽 Σ
        s += i + j;
// s = 1100
Pythondouble.py
s = sum(i + j
        for i in range(1, 11)
        for j in range(1, 11))
print(s)  # 1100

수학적 풀이 (기출 핵심 테크닉)

ΣΣ(i+j) = Σi[ Σji + Σjj ] = Σi[ 10i + 55 ] = 10·55 + 55·10 = 1100

안쪽 시그마에서 i는 상수 취급된다는 것이 핵심입니다. 이 감각은 4번 탭 시뮬레이터로 눈으로 확인하세요.

3-5단계 4 — 위끝이 변수인 시그마 (삼각형 루프)

난이도 ★★★ 기출 최다 출제

안쪽 범위가 바깥 변수에 의존하는 형태. "이 코드는 몇 번 실행되는가?" 유형의 정체가 바로 이것입니다.

Σi=1n Σj=in 1 = Σi=1n (n−i+1) = n + (n−1) + ... + 1 = n(n+1)/2
Ccount.c
int cnt = 0;
for (int i = 1; i <= n; i++)
    for (int j = i; j <= n; j++)  // j가 i부터!
        cnt++;
// n=8 → cnt = 8·9/2 = 36
Pythoncount.py
cnt = 0
for i in range(1, n + 1):
    for j in range(i, n + 1):
        cnt += 1
# n=8 → cnt = 36 (i≤j인 쌍의 개수)
암기 카드 — j가 i부터 시작(i≤j 허용): n(n+1)/2  /  j가 i+1부터 시작(i<j): n(n−1)/2. 시간복잡도는 둘 다 O(n²)!

4-1이중 시그마 그리드 시뮬레이터

이중 for문의 실행을 (i, j) 격자로 시각화합니다. 셀 하나 = 안쪽 루프 1회 실행. 루프 형태를 바꾸면 칠해지는 모양(정사각형 vs 삼각형)이 달라지고, 그 셀의 개수·합이 곧 시그마 값입니다.

설정 후 [실행]을 누르면 셀이 하나씩 칠해집니다.
관찰 포인트 — ① 정사각형과 삼각형의 셀 개수 비교 (n² vs n(n+1)/2)  ② 바깥 i가 고정된 채 안쪽 j만 도는 "행 단위" 진행  ③ 대각선(i=j) 포함 여부가 두 삼각형 공식의 차이.

4-2O(n) 루프 vs O(1) 공식 — 속도 대결

같은 답이라도 공식은 계산 1번, 루프는 n번입니다. n이 커질 때의 차이를 확인하세요. 올림피아드 실전에서 n이 109처럼 크면 루프는 시간초과 — 공식만이 살길입니다.

n을 입력하고 대결을 시작하세요. (브라우저에서 실제 실행 시간을 측정합니다)
실전 주의 — n=100000일 때 Σi = 5,000,050,000 은 int 범위(약 21억)를 초과합니다. C에서는 long long, 공식 계산 시에는 n(n+1)이 먼저 곱해지므로 더욱 주의!
