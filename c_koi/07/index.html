07

중첩 반복과 격자 패턴

바깥 루프가 행, 안쪽 루프가 열이다. 이 한 문장이 2차원 세계의 전부이며, 9장의 2차원 배열과 PART 3의 격자 탐색이 모두 여기서 출발한다. 이 장의 목표는 (i, j)로부터 값을 계산하는 규칙을 세우는 훈련이다.

학습 목표

  • 이중 루프에서 바깥·안쪽 변수가 행과 열에 대응한다는 것을 이해한다
  • 안쪽 루프의 범위를 바깥 변수에 의존시켜 삼각형 모양을 만들 수 있다
  • 공백 개수와 별 개수를 행 번호 i의 식으로 유도할 수 있다
  • N×N 나선의 각 칸 값을 배열 없이 좌표만으로 계산할 수 있다
  • 이중·삼중 루프의 반복 횟수를 세고 통과 가능성을 판단할 수 있다

02 — 개념 정리

개념 정리

7.1바깥은 행, 안쪽은 열

printf("\n")의 위치가 구조를 결정한다. 안쪽 루프 밖, 바깥 루프 안이다. 안쪽에 넣으면 세로 한 줄이 되고, 바깥 밖으로 빼면 전부 한 줄이 된다.

안쪽 루프는 바깥 루프가 한 칸 갈 때마다 처음부터 끝까지 다시 돈다. 그래서 총 반복 횟수는 곱이다.

구조총 횟수용도
i: 0~N-1 × j: 0~N-1N²격자 전체
i: 0~N-1 × j: 0~iN(N+1)/2삼각형, 아래쪽 절반
i: 0~N-1 × j: i+1~N-1N(N−1)/2모든 쌍 — 중복 없이
i × j × k 모두 NN³세 개 고르기

세 번째 줄이 특히 중요하다. j = i + 1부터 시작하면 (1,2)와 (2,1)을 중복해서 세지 않는다. N = 6이면 15쌍이고, 이것이 6 × 5 / 2와 일치한다. PART 2의 완전탐색에서 계속 쓰인다.

id공백 = h − d별 = 2d + 1

위쪽과 아래쪽을 따로 쓰지 않는다. 한 루프 안에서 d만 바꿔 처리하므로 1만큼 어긋나는 사고가 생길 자리가 없다.

이 발상은 계속 쓰인다 min(i, N-1-i)는 "위아래 경계 중 가까운 쪽까지의 거리"다. 행과 열 양쪽에 적용하면 min(i, j, N-1-i, N-1-j)가 되고, 이것이 바로 격자의 몇 번째 테두리인가를 알려 준다. 표준 코드의 나선이 이 한 줄에서 출발한다.

7.5삼중 루프와 복잡도의 출발

루프를 하나 더 겹치면 횟수는 N배가 된다. 6장의 실측표를 삼중 루프로 다시 재면 아래와 같다.

NN³ 반복 횟수실측 시간판단
1001,000,0000.003 초여유
30027,000,0000.063 초여유
1,0001,000,000,0002.299 초시간 초과

삼중 루프는 N이 500 정도까지가 한계다. 문제의 제약에 N ≤ 100이 적혀 있으면 "삼중 루프를 써도 된다"는 출제자의 신호이고, N ≤ 100,000이 적혀 있으면 "이중 루프조차 쓰지 말라"는 뜻이다.

제약 조건은 힌트다 6장에서 "N을 보고 알고리즘을 고른다"고 했다. 거꾸로도 성립한다. N의 크기가 곧 출제자가 의도한 알고리즘의 복잡도다. 문제를 읽자마자 N부터 확인하는 습관을 들인다.
03 — 표준 코드

표준 코드: N×N 나선

1부터 N²까지를 바깥에서 안쪽으로 시계 방향으로 채운 모습이다. 배열은 9장에서 배우므로, 여기서는 각 칸의 값을 좌표만으로 계산한다.

N = 4
  1  2  3  4
 12 13 14  5
 11 16 15  6
 10  9  8  7
N = 5
  1  2  3  4  5
 16 17 18 19  6
 15 24 25 20  7
 14 23 22 21  8
 13 12 11 10  9

1단계 — 몇 번째 테두리인가

7.3절의 발상을 네 방향으로 확장한다. 칸 (i, j)가 속한 테두리 번호는 네 경계까지의 거리 중 가장 작은 값이다.

2단계 — 그 테두리가 몇 번부터 시작하는가

테두리 r의 안쪽은 한 변이 m = N − 2r인 정사각형이다. 그보다 바깥쪽 테두리들이 이미 쓴 숫자의 개수는 N² − m²개다. 따라서 테두리 r의 첫 숫자는 그다음 수다.

3단계 — 그 테두리 안에서 몇 번째인가

테두리를 시계 방향으로 돌며 위·오른쪽·아래·왼쪽 네 구간으로 나눈다. 각 변의 길이는 m − 1이다.

요소설명
r테두리 번호. 7.3절의 min 발상을 네 방향으로 쓴 것
m = N - 2r그 테두리가 둘러싼 정사각형의 한 변
s = N*N - m*m더 바깥쪽에서 이미 쓴 숫자의 개수
k테두리 안에서 0부터 센 순서. 네 구간을 else if로 나눈다(5장)
분기 순서위 → 오른쪽 → 아래 → 왼쪽. 모서리 칸이 두 조건을 동시에 만족하므로, 먼저 쓴 쪽이 이긴다. 순서를 바꾸면 모서리 값이 틀린다
가운데 한 칸N이 홀수면 마지막에 m = 1인 경우가 생긴다. 이때 s = N² − 1, k = 0이 되어 값이 N²으로 정확히 맞는다
이 코드를 외울 필요는 없다 외울 것은 세 단계로 쪼갠 사고 과정이다. "어느 테두리인가 → 그 테두리는 몇 번부터인가 → 그 안에서 몇 번째인가". 9장에서 2차원 배열을 배우면 나선은 훨씬 쉽게 풀린다(그냥 채워 넣으면 된다). 그럼에도 이 방식을 먼저 해 보는 이유는, 저장하지 않고 계산해 내는 사고가 PART 3·4의 수학 문제에서 필요하기 때문이다.

05 — 흔한 오류

흔한 오류 여섯 가지

오류 1줄바꿈 위치를 잘못 잡았다

이 장에서 가장 많이 나오는 실수이고, 경고는 없다.

for (i...) { for (j...) { printf("*"); printf("\n"); } }  // 세로 한 줄
for (i...) { for (j...) { printf("*"); } } printf("\n");  // 전부 한 줄
for (i...) { for (j...) { printf("*"); } printf("\n"); }  // 올바름
고치는 법 — printf("\n")은 안쪽 루프의 닫는 괄호 다음, 바깥 루프의 닫는 괄호 앞. 위치를 외운다.
오류 2안쪽 루프 변수를 초기화하지 않았다

for를 쓰면 생기지 않지만, while로 중첩하면 반드시 걸린다.

int j = 0;
while (i < N) {
    while (j < N) { ... j++; }   // 두 번째 i부터 j가 이미 N이다
    i++;
}

첫 행만 출력되고 나머지는 빈 줄이 된다. 안쪽 루프 변수는 바깥 루프가 돌 때마다 다시 초기화되어야 한다.

고치는 법 — 중첩 반복은 for로 쓴다. for (int j = 0; ...)는 매번 자동으로 초기화된다.
오류 3두 루프에 같은 변수를 썼다
for (int i = 0; i < N; i++) {
    for (i = 0; i < N; i++) { ... }   // j가 아니라 i
}

안쪽이 i를 N까지 올려놓으므로 바깥은 한 번 돌고 끝난다. 변수를 새로 선언하지 않고 바깥 것을 재사용한 경우에만 생기며, 경고가 없다.

고치는 법 — 안쪽 루프는 항상 for (int j = ...)처럼 새로 선언한다. 변수 이름은 i, j, k 순서로 쓴다.
오류 4공백과 별의 개수가 1만큼 어긋났다

패턴 문제의 거의 모든 오답이 여기에 속한다. i를 0부터 셀지 1부터 셀지 정하지 않고 쓰기 시작하면 반드시 생긴다.

고치는 법 — 코드를 쓰기 전에 작은 N에 대한 표를 손으로 만든다. i, 공백 개수, 별 개수를 적고 i의 식으로 유도한 뒤 코딩한다. 그리고 매 줄의 총 글자 수가 일정한지로 검산한다.
오류 5모서리를 두 번 세거나 빠뜨렸다

테두리를 네 변으로 나눌 때 생긴다. 네 모서리는 두 변에 동시에 속하기 때문이다.

// 테두리 길이를 4 * N 으로 계산 → 모서리를 두 번 셈
// 올바른 값은 4 * N - 4 또는 4 * (N - 1)

표준 코드가 이 문제를 else if 체인으로 해결했다. 앞의 조건에 걸린 칸은 뒤 조건을 보지 않으므로 모서리가 한 번만 세어진다(5장).

고치는 법 — 구간을 나눌 때 경계가 어느 쪽에 속하는지 먼저 정하고, else if로 겹치지 않게 만든다. N = 1, 2, 3의 작은 경우로 검산한다.
오류 6반복 횟수를 세지 않고 중첩했다

이중 루프는 N = 10,000이 한계, 삼중 루프는 N = 500 정도가 한계다. 그 이상에서는 코드가 아무리 정확해도 통과하지 못한다.

N = 100,000 에서 이중 루프 → 10^10 번 → 약 100초
고치는 법 — 루프를 겹치기 전에 N을 대입해 곱해 본다. 1억을 넘으면 알고리즘 자체를 바꿔야 한다는 신호다.
이 장의 가장 중요한 교훈 패턴 문제를 바로 코딩하지 않는다. 작은 N에 대한 표를 손으로 만들고, 공백·별 개수를 i의 식으로 유도하고, 총 글자 수로 검산한 다음에 코드를 쓴다. 이 순서를 지키면 off-by-one이 거의 사라진다.

07 — 확인 평가 해설

정답과 해설

※ 이 절은 교사용 통합본에만 수록한다. 학생 배부용에서는 제거한다.

01
for (i=0;i<H;i++) { for (j=0;j<W;j++) printf("*"); printf("\n"); } — 바깥이 세로(H), 안쪽이 가로(W)다. 뒤바꾸는 학생이 많으니 출력으로 확인시킨다.
02
예제 1과 동일. j <= i가 핵심이다.
03
for (i=N;i>=1;i--) 또는 for (i=0;i<N;i++)에 j < N-i. 두 방법을 모두 보여 주고 어느 쪽이 읽기 쉬운지 토론시킨다.
04
공백 N−i개, 별 i개(i는 1부터). 검산: 합이 항상 N. 흔한 오답 — i를 0부터 세면서 식을 그대로 쓰면 한 줄이 어긋난다.
05
for (i=2;i<=9;i++) { for (j=1;j<=9;j++) printf("%4d", i*j); printf("\n"); } — 8행 9열, 총 72번. 3장의 폭 지정이 여기서 쓰인다.
06
printf("%d", j)로 j를 그대로 찍는다. 10 이상이 되면 자릿수가 달라져 모양이 흐트러지므로 N ≤ 9로 제한하거나 폭을 지정해야 한다는 점을 짚는다.
07
(i==0 || i==N-1 || j==0 || j==N-1) ? '*' : ' ' — N = 1일 때 * 하나, N = 2일 때 ** 두 줄이 나오는지 확인시킨다.
08
((i+j) % 2 == 0) ? '#' : '.' — i+j의 홀짝이 체스판 색과 같다는 것이 핵심 발상이다. PART 3의 이분 그래프 판정에서 다시 나온다.
09
예제 3과 동일. d = (i <= h) ? i : (N-1-i). 검산 — 공백 + 별 + 공백 = N이 항상 성립해야 한다. 오른쪽 공백은 출력하지 않으므로 눈으로는 안 보이지만 식으로는 맞아야 한다.
10
9번에서 별을 찍는 루프를 조건부로 바꾼다. 테두리는 맨 처음과 맨 마지막 별이다. 
for (int j = 0; j < 2*d+1; j++) {
    printf("%c", (j == 0 || j == 2*d) ? '*' : ' ');
}
주의 — d = 0인 줄(맨 위·맨 아래)에서는 j==0과 j==2*d가 같은 칸을 가리킨다. 별이 하나만 찍히는 것이 정답이다. 오류 5의 모서리 중복과 같은 구조다.
11
(i == j || i + j == N-1) ? '*' : ' ' — N이 홀수면 가운데에서 두 조건이 동시에 참이지만, ||이므로 별 하나만 찍힌다. 조건을 ||로 합치면 중복이 자동으로 해결된다는 점이 이 문제의 교훈이다.
12
표준 코드의 1단계만 떼어 낸다. 
int r = i;
if (j < r) { r = j; }
if (N-1-i < r) { r = N-1-i; }
if (N-1-j < r) { r = N-1-j; }
printf("%d", r);
N = 5의 출력이 동심원 모양으로 나오는 것을 확인시킨다. 이 그림을 본 학생은 18번에서 훨씬 쉽게 접근한다.
13
행 우선 i*N+j+1, 열 우선 j*N+i+1. 지도 포인트 — 9장에서 a[i][j]가 메모리에 행 우선으로 놓인다는 사실을 배울 때 이 문제를 다시 꺼낸다.
14
for (i=1;i<=N;i++) for (j=i+1;j<=N;j++) — N = 4에서 6쌍, 4×3/2 = 6과 일치. 지도 포인트 — j를 1부터 시작하고 if (i != j)로 거르면 12쌍이 되어 중복이 생긴다. 두 방법을 모두 실행해 비교시킨다.
15
예제 5와 동일. N = 300이면 약 300³/6 ≈ 450만번으로 충분히 빠르다. 정확히는 C(300+2,3) 정도이며, 삼중 루프의 상한을 b, a에 묶었으므로 전체 N³의 약 1/6이다.
16
for (int a = 1; a <= N; a++) {
    for (int b = a; b <= N; b++) {
        int s = a*a + b*b;
        int c = 0;
        while ((c+1)*(c+1) <= s) { c++; }   // 정수 제곱근
        if (c*c == s && c <= N) { printf("%d %d %d\n", a, b, c); }
    }
}
더 간단하게는 c를 b부터 올리는 대신, a·b가 커질 때 c도 단조 증가한다는 성질을 이용해 바깥에서 c를 유지하는 방법도 있다(투 포인터의 맹아, PART 3).
횟수 비교 — 삼중은 약 N³/6, 이중은 약 N²/2. N = 1,000이면 1.7억 vs 50만으로 300배 이상 차이가 난다.
주의 — sqrt()로 구한 뒤 (int)로 자르면 오차 때문에 1 작은 값이 나올 수 있다(2장). 정수 루프로 구하거나, 구한 뒤 c*c == s로 반드시 재확인한다.
17
N = 5의 r 격자는 12번과 같다. s 격자는 r = 0인 칸이 0, r = 1인 칸이 25 − 9 = 16, r = 2인 칸이 25 − 1 = 24다.
설명 — 테두리 r을 채우기 직전까지 쓴 숫자의 개수가 s다. 바깥 테두리 하나가 m² − (m−2)² = 4m − 4개의 칸을 차지하므로, 안쪽으로 들어갈수록 s가 그만큼씩 커진다. 5×5에서는 0 → 16(바깥 테두리 16칸) → 24(두 번째 테두리 8칸) 순이다.
18
표준 코드와 동일. N = 1 → 1, N = 2 → 1 2 / 4 3.
순서를 바꾸면 — 예를 들어 "오른쪽 변"을 "위쪽 변"보다 먼저 검사하면, 오른쪽 위 모서리 (r, N−1−r)가 오른쪽 변으로 분류되어 값이 틀어진다. N = 4에서 (0,3) 칸이 4가 아니라 다른 값이 된다.
지도 포인트 — 모서리가 두 조건을 동시에 만족하므로 else if의 순서가 곧 "모서리를 어느 변에 넣을 것인가"의 결정이다. 5장의 "겹치지 않게"가 여기서 구체적으로 쓰인다.
19
표를 먼저 만든다(i는 1부터 N).
i공백숫자 부분
131
22121
3112321
401234321
공백은 N − i개. 숫자는 1부터 i까지 올라갔다가 i−1부터 1까지 내려온다. 길이는 2i − 1. 
for (int i = 1; i <= N; i++) {
    for (int j = 0; j < N - i; j++) { printf(" "); }
    for (int j = 1; j <= i; j++)    { printf("%d", j); }
    for (int j = i - 1; j >= 1; j--){ printf("%d", j); }
    printf("\n");
}
검산 — (N−i) + (2i−1) = N + i − 1. 줄마다 달라지는 것이 맞다(오른쪽 공백이 없으므로). 숫자 부분 길이만 2i−1로 확인한다.

⑴ 이중, 10⁶번, 통과.
⑵ 이중, 10¹⁰/2 = 5×10⁹번, 불가(약 50초). 정렬 후 한 번 훑기나 투 포인터로 N log N까지 줄여야 한다(PART 3).
⑶ 삼중, 500³/6 ≈ 2×10⁷번, 통과. 상한을 묶어 1/6로 줄인 것이 결정적이다.
⑷ 이중, 3000²/2 = 4.5×10⁶번, 통과.
지도 포인트 — ⑵와 ⑷가 같은 "모든 쌍 검사"인데 결과가 갈린다. 알고리즘이 아니라 N이 가능 여부를 정한다. 이 판단을 코딩 전에 하는 것이 PART 2의 첫 번째 훈련 항목이다.
08 — 마무리

이 장을 마치기 전 점검

  • 바깥 루프가 행, 안쪽 루프가 열이라는 틀을 외우고 있다
  • printf("\n")을 안쪽 루프 밖, 바깥 루프 안에 둔다
  • 패턴 문제를 코딩 전에 표로 만들어 i의 식을 유도한다
  • 대칭 패턴을 d = min(i, N-1-i)로 한 번에 처리한다
  • 격자 조건(대각선·테두리·체스판)을 (i, j)의 식으로 쓸 수 있다
  • 중복 없는 쌍을 j = i + 1로 만든다
  • 루프를 겹치기 전에 N을 대입해 횟수를 곱해 본다
  • 구간을 나눌 때 경계가 어느 쪽에 속하는지 먼저 정한다
다음 장 예고 — 08장 1차원 배열 지금까지는 값을 계산해서 바로 버렸다. 입력을 모두 저장해 두고 여러 번 들여다봐야 하는 문제가 곧 나온다. 배열을 배우면 나선도 "계산"하지 않고 "채워 넣으면" 되고, 카운팅 배열이라는 강력한 도구도 손에 들어온다.
