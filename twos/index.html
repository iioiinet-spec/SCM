두 원의 공통접선과 닮음의 중심 실습실

PC₁ : PC₂ = ℓ₁ : ℓ₂ = r₁ : r₂

두 원에 동시에 접하는 두 직선(공통접선)은 한 점 P에서 만납니다. 이 P(닮음의 중심)에서 두 원의 중심까지의 거리의 비, 접선 길이의 비가 모두 반지름의 비 r₁ : r₂와 같고, 접선과 각 원의 중심 사이의 거리는 정확히 그 원의 반지름임을 드래그하며 확인하세요.

좌표평면 — 중심·반지름 핸들을 드래그하세요

원1 a₁ b₁ r₁ 원2 a₂ b₂ r₂
파란 점 P = 두 공통접선의 교점(닮음의 중심) · 분홍 점선 = 중심선(P, C₁, C₂는 한 직선 위!) · 흰 선분 = 접선까지의 수직 거리(= 반지름) · 초록 점 = 접점

두 원과 닮음의 중심 P

거리의 비율 — 닮음의 핵심

접선의 방정식과 중심까지의 거리

학습 포인트

1. 왜 한 점에서 만날까? — 두 원은 서로 닮음이고, 공통접선은 닮음의 중심 P를 지납니다. 외부 공통접선의 P는 중심선 C₁C₂를 r₁ : r₂로 외분, 내부 공통접선의 P는 r₁ : r₂로 내분한 점.
2. 거리의 비 — 닮음비가 r₁ : r₂이므로 PC₁ : PC₂ = r₁ : r₂, 접선 길이도 ℓ₁ : ℓ₂ = r₁ : r₂ (직각삼각형의 닮음).
3. 접선의 판정 — 한 직선이 원에 접한다 ⇔ 중심에서 그 직선까지의 거리 = 반지름. 카드의 검증이 두 원 모두에서 성립하므로 "공통"접선!
4. 존재 조건 — 외부 공통접선: d > |r₁−r₂| 이면 2개. 내부 공통접선: d > r₁+r₂ (두 원이 떨어져 있을 때)만 2개. 그래서 공통접선 개수가 4→3→2→1→0으로 변합니다.
5. 반지름이 같으면? — 외부 공통접선이 평행해져 만나는 점이 없습니다(무한원점). 내부 공통접선은 여전히 중점에서 만납니다.
