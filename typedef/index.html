C typedef + Struct — Memory Model

매번 struct라 쓰지 않고,
구조체에 새 이름을 붙이기.

typedef는 기존 자료형에 별명을 붙여주는 문법입니다. 구조체와 함께 쓰면 struct Student라는 긴 이름을 Student 한 단어로 줄일 수 있습니다. 메모리 구조나 동작은 일반 구조체와 완전히 같고, 이름을 쓰는 방식만 달라집니다.

struct Student s1; → typedef → Student s1;
01 · 기초 문법

typedef란 무엇인가

typedef는 새로운 자료형을 만드는 것이 아니라, 이미 있는 자료형에 별명(alias)을 붙이는 키워드입니다. 지난 강의에서 만든 struct Student는 변수를 선언할 때마다 struct 키워드를 꼭 앞에 붙여야 했습니다. typedef를 쓰면 이 키워드를 매번 쓰지 않아도 됩니다.

① 일반 변수에 쓰는 typedef (구조체가 아니어도 가능)

typedef_basic.c
typedef unsigned int uint;   // unsigned int 의 별명이 uint

uint count = 10;   // unsigned int count = 10; 과 완전히 동일

typedef는 사실 구조체 전용 문법이 아닙니다. 기존 자료형 옆에 새 이름을 적어주는 일반적인 규칙(typedef 기존타입 새이름;)이고, 구조체는 그 대상 중 하나일 뿐입니다.

② 구조체에 typedef 적용하기

typedef_struct.c
typedef struct {
    char name[20];
    int age;
    float score;
} Student;   // 이 익명 구조체 전체의 별명이 Student

Student s1 = {"김민준", 17, 92.5};   // struct 없이 바로 선언

여기서 struct 뒤에 이름이 없다는 것에 주목하세요. 이런 구조체를 익명 구조체(anonymous struct)라고 부릅니다. 원래는 이름이 없어서 변수를 선언할 방법이 없었는데, typedef가 그 자리 전체에 Student라는 이름을 붙여준 것입니다.

핵심 — typedef는 메모리 구조를 전혀 바꾸지 않습니다. char[20] + int + float = 28바이트라는 사실은 그대로입니다. 바뀌는 것은 오직 컴파일러에게 이 자료형을 어떤 이름으로 부를지 뿐입니다.
02 · 문법 비교

세 가지 선언 방식, 무엇이 다른가

현업 코드와 교과서에서 아래 세 가지 방식을 모두 볼 수 있습니다. 셋 다 같은 메모리 구조를 만들지만, 변수를 선언할 때 타이핑하는 방식이 다릅니다.

방식 A · 구조체 태그만 사용
struct Student {
    char name[20];
    int age;
};

struct Student s1;  // struct 필수
방식 B · 태그 + typedef 별도
struct Student {
    char name[20];
    int age;
};
typedef struct Student Student;

Student s1;  // struct 생략 가능
방식 C · 익명 구조체 + typedef (가장 흔한 방식)
typedef struct {
    char name[20];
    int age;
} Student;   // 태그 이름 없이 바로 typedef

Student s1;  // struct 생략 가능, 태그 이름 자체가 없음
방식구조체 태그변수 선언메모리 구조
A. 태그만struct Studentstruct Student s1;동일
B. 태그 + typedefstruct StudentStudent s1; 또는 struct Student s1;동일
C. 익명 + typedef없음Student s1;동일
실전 팁 — 특별한 이유가 없다면 방식 C가 가장 간결해서 널리 쓰입니다. 다만 구조체 내부에서 자기 자신을 가리키는 포인터가 필요한 경우(연결 리스트의 노드 등)에는 태그 이름이 필요해, 방식 B처럼 태그를 남겨두기도 합니다.

04 · typedef 구조체와 포인터

  
Student *p — struct 없이 포인터 선언하기

  
포인터 선언에서도 struct 키워드가 사라지는 효과는 그대로 이어집니다. struct Student *p 대신 Student *p라고만 쓰면 됩니다. 접근 방법(->, (*p).)은 지난 강의와 똑같습니다.


  
typedef_ptr.c

  
Student s1 = {"박지후", 16, 88.5};
Student *p = &s1;      // struct 없이 포인터 선언

p->age = 20;             // 화살표 연산자, 의미는 이전과 동일
(*p).score = 100.0;      // 역참조 + 점 연산자, 위와 동일

05 · 핵심: 포인터를 배열처럼

  
포인터로 typedef 구조체 배열 다루기

  
malloc으로 여러 개를 한 번에 할당할 때도 struct 키워드만 빠질 뿐, 원리는 동일합니다. arr[i], *(arr+i), (arr+i)->field는 여전히 같은 메모리를 가리킵니다.


  
typedef_array.c

  
Student *arr = (Student *)malloc(sizeof(Student) * 5);  // struct 없이 sizeof(Student)

for (int i = 0; i < 5; i++) {
    sprintf(arr[i].name, "학생%d", i + 1);
    arr[i].age = 15 + i;
    arr[i].score = 70.0 + i * 5;
}

for (int i = 0; i < 5; i++) {
    printf("%s (%d세) - %.1f점\n", arr[i].name, arr[i].age, arr[i].score);
}
free(arr);

핵심 공식 — arr + i의 주소는 여전히 base + i × sizeof(Student)입니다. typedef는 이름만 줄여줄 뿐 sizeof(Student)의 값(28바이트) 자체는 sizeof(struct Student)와 정확히 같습니다.
