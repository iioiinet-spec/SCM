C Struct — Memory Model

서로 다른 자료형을,
하나의 메모리 덩어리로.

구조체(struct)는 여러 개의 변수를 하나의 이름 아래 묶어, 나란히 붙어 있는 메모리 조각으로 만드는 문법입니다. 이 강의에서는 구조체의 문법부터, 포인터로 구조체를 가리키는 법, 그리고 포인터를 배열처럼 움직여 여러 구조체를 한 번에 다루는 법까지 직접 만져보며 익힙니다.

01 · 기초 문법

구조체란 무엇인가

배열은 같은 자료형을 여러 개 묶습니다. 구조체는 서로 다른 자료형을 하나의 이름으로 묶습니다. 학생 한 명을 표현하려면 이름(문자열), 나이(정수), 점수(실수)가 모두 필요한데, 이걸 각각 따로 변수로 만들면 관리가 번거롭습니다. 구조체는 이 세 가지를 Student라는 하나의 새로운 자료형으로 합쳐줍니다.

① 구조체 선언 — 새로운 자료형의 설계도

struct.c
struct Student {
    char name[20];   // 이름 (문자 배열)
    int age;         // 나이
    float score;     // 점수
};  // 세미콜론을 꼭 붙여야 합니다

이 구문은 변수를 만드는 것이 아니라, Student라는 이름의 새 자료형을 설계하는 것입니다. int가 원래 있던 자료형이듯, 이제부터 struct Student도 하나의 자료형처럼 쓸 수 있습니다.

NOTE — 구조체 안에서는 배열의 크기(char name[20])처럼 고정된 크기만 선언할 수 있습니다. 크기가 상황마다 달라져야 한다면 이후 배울 포인터와 malloc이 필요합니다.

② 변수 선언과 초기화

struct.c
// 방법 1: 선언 후 순서대로 초기화
struct Student s1 = {"김민준", 17, 92.5};

// 방법 2: 멤버 이름을 지정해서 초기화 (C99 이후)
struct Student s2 = { .age = 16, .score = 88.0, .name = "이서연" };

// 방법 3: 먼저 선언하고 나중에 하나씩 대입
struct Student s3;
s3.age = 18;
s3.score = 95.0;

중괄호 초기화는 선언과 동시에만 가능합니다. 이미 선언된 구조체 변수에는 s3 = {18, 95.0}; 처럼 다시 통째로 대입할 수 없고, 멤버 하나씩 .(점) 연산자로 접근해야 합니다.

③ 멤버 접근 — 점(.) 연산자

printf("이름: %s, 나이: %d, 점수: %.1f\n", s1.name, s1.age, s1.score);
s1.age = s1.age + 1;  // 생일이 지나 나이를 1 올림

구조체 변수 뒤에 마침표를 찍고 멤버 이름을 쓰면, 그 멤버 하나만 정확히 골라서 읽고 쓸 수 있습니다.

④ typedef로 이름 줄이기

typedef struct {
    char name[20];
    int age;
    float score;
} Student;

Student s1 = {"김민준", 17, 92.5};  // 이제 struct 를 매번 안 써도 됨

⑤ 메모리 관점에서 본 구조체

구조체 변수를 하나 만들면, 컴퓨터는 각 멤버가 차지할 만큼의 공간을 순서대로, 나란히 붙여서 확보합니다. Student는 char[20](20바이트) + int(4바이트) + float(4바이트) = 총 28바이트짜리 연속된 메모리 조각이 됩니다.

핵심 — 구조체는 변수들의 "묶음"이 아니라, 실제로 메모리 위에 나란히 붙어 있는 하나의 덩어리입니다. 이 사실이 다음 섹션에서 포인터로 구조체를 다루는 이유가 됩니다.

03 · 포인터와 구조체

  
구조체를 가리키는 포인터

  
구조체 변수도 결국 메모리 위의 한 덩어리이므로, 그 시작 주소를 포인터에 담을 수 있습니다. 포인터를 통해 구조체를 다루면, 원본을 복사하지 않고도 원본을 직접 읽고 고칠 수 있습니다.


  
① 문법: 선언과 두 가지 접근법

  
struct_ptr.c

  
struct Student s1 = {"박지후", 16, 88.5};
struct Student *p = &s1;   // p는 s1의 주소를 저장

// 접근법 1: 화살표 연산자 (가장 많이 씀)
p->age = 20;

// 접근법 2: 역참조 후 점 연산자 — 위와 완전히 동일
(*p).age = 20;

  
p->age는 (*p).age의 축약형일 뿐, 의미는 똑같습니다. *p로 먼저 구조체 자체를 얻고, .age로 멤버에 접근하는 과정을 화살표 하나로 줄인 것입니다.


  

    
LIVE · struct Student s1, *p = &s1

    
아래 버튼을 눌러 포인터를 통해 s1의 값을 바꿔보세요. p는 별도 저장 공간이지만, 가리키는 대상은 s1 그 자체입니다.


    

    
p (0x7F00) ──▶ s1 (0x3000)


    

      
      
      
    

    
실행된 코드 로그

    
// 버튼을 눌러 실행해 보세요

  


  
왜 이게 중요한가 — 만약 함수에 구조체를 값으로 전달하면(void f(struct Student s)), 함수 안에서는 복사본을 고치는 것이라 원본은 그대로입니다. 반대로 주소를 전달하면(void f(struct Student *p)), 함수 안에서 p->age = 20처럼 고치는 순간 원본 s1이 바뀝니다. 방금 실습이 바로 그 원리입니다.







  
04 · 핵심: 포인터를 배열처럼

  
포인터로 구조체 배열 다루기

  
학생 한 명이 아니라 여러 명을 관리하려면 구조체 배열이 필요합니다. 이때 배열 이름은 사실 그 배열의 첫 번째 원소를 가리키는 포인터처럼 동작합니다. 그래서 arr[i]와 *(arr + i)는 완전히 같은 것을 가리킵니다 — 단, 구조체 배열에서는 +1이 sizeof(struct)만큼 건너뛴다는 점이 다릅니다.


  
① malloc으로 구조체 배열 만들기

  
struct_array.c

  
struct Student *arr = (struct Student *)malloc(sizeof(struct Student) * 5);

for (int i = 0; i < 5; i++) {
    sprintf(arr[i].name, "학생%d", i + 1);
    arr[i].age = 15 + i;
    arr[i].score = 70.0 + i * 5;
}

for (int i = 0; i < 5; i++) {
    printf("%s (%d세) - %.1f점\n", arr[i].name, arr[i].age, arr[i].score);
}
free(arr);


  
② 세 가지 표현, 같은 메모리

  
arr[i], *(arr+i), (arr+i)는 모두 같은 구조체를 가리킵니다. 아래에서 인덱스를 움직이며 세 표현이 정확히 같은 칸을 가리키는 것을 확인해 보세요.

arr[i].field

      
(*(arr + i)).field

      
(arr + i)->field

표의 age, score 칸은 직접 클릭해서 값을 바꿀 수 있습니다 — 위 코드의 arr[i].age = ... 한 줄이 실제로 하는 일과 같습니다.

  


  
핵심 공식 — arr + i가 가리키는 주소는 base + i × sizeof(struct Student) 입니다. int 배열이었다면 원소당 4바이트씩 건너뛰지만, 구조체 배열은 원소당 구조체 전체 크기(여기서는 28바이트)씩 건너뜁니다. 포인터의 +1은 "1바이트 이동"이 아니라 "그 포인터가 가리키는 자료형 하나만큼 이동"이라는 뜻이기 때문입니다.
